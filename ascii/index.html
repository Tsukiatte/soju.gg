Run it yourself

Both files, plus a tiny run.html that draws the scene full-window. Browsers only load module scripts from a server, so serve the folder first.

  1. 1
    Download the zip or save fuji.js in scenes/, ascii.js in engine/ and run.html beside them.
  2. 2
    In that folder run python -m http.server 8000 or npx serve.
  3. 3
    Open http://localhost:8000/run.html. Edit the scene, reload, watch it change.

how it works

  1. 1

    3D points

    A scene is a cloud of about 100,000 coloured points in 3D: a mountain, a lake, a pagoda, drawn as numbers.

  2. 2

    Light per letter

    Each point lands in one cell of a grid. How much light it catches picks the letter, from a dot to an @, and its colour.

  3. 3

    30 times a second

    The camera turns a little, the grid is drawn again, and the reel loops. The same code runs in this page.
